# 二用途の事前検査の実行記録（2026-10-25）

合成のゲーム・MOD・保存先を用意し、既存の入力監査テストも含めた 59 テストをローカルで実行した。Linux ではネイティブ Windows の Tk 画面生成 1 件を除き通過した。Windows 側の画面生成と両 OS の Python 3.12/3.13 は CI で別途確認する。

独立した読取専用レビューを 1 回実施。読めないディレクトリを os.walk が省略する問題と、symlink 経由で出力先が保護対象から外れる問題を再現し、診断・リンク拒否・字面と解決後の両方での出力保護に変更した。再現テストが失敗することと、修正後の全テストの通過を確認した。

保存先引数は受領済みの `Assembly-CSharp.dll` で、`Verse.GenFilePaths.get_SaveDataFolderPath` が `Verse.GenCommandLine.TryGetCommandLineArg`（`0x060037db`）を呼ぶ経路を静的に確認した。引数ごとに `=` で分割して 2 要素を要求するため、通常起動コマンドは `-savedatafolder=...` を 1 引数とし、値自体に `=` を含む場合などは起動前に拒否する。ゲームでの通常起動を実行した結果ではない。IL 本文は公開していない。

## 受領資料を使った追加確認

非公開の一時領域に、受領済みの実行ファイル・主要 DLL と、Data の Core/About・Core/Defs をコピーし、新規の Core のみの ModsConfig を用意した。CLI は XML 554 個を構文解析し、563 ファイルを fingerprint に含めて `auditStatus=passed`、`gameVerification=notRun` を返した。

このケースの経過時間はローカル環境で約 0.21 秒だった。Core だけ・素材なし・ファイルがキャッシュされ得る小さなケースであり、多数 MOD の実測や、ユーザーの PC における通常起動との速度比較ではない。公式 Data 全体の再現、翻訳、実行時の参照解決、Harmony を検証した数値ではない。

元の受領 ZIP と設定・セーブは変更していない。実ファイル、ModsConfig、プロフィール、結果 JSON は公開対象外の一時領域に置き、公開するのはこの集計と自作のテスト・実装のみ。
