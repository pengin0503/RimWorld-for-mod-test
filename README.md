# RimWorld-for-mod-test

RimWorld 1.7 unstable の公式ヘッドレス起動を使い、Linux x86_64 上で MOD の読み込みを検証するためのプロジェクトです。

**現在は調査・設計段階です。実行可能な検証ツールはまだありません。**

## 対象

- A：Defs、XML パッチ、選択した言語の読み込み検証。
- B：MOD の DLL と、起動時点の Harmony パッチの適用先の確認。
- マップ生成、tick、プレイ中の動作検証は後続段階で判断します。

ゲーム本来の起動処理を通します。独自の Defs ローダーや、画面・操作を提供するゲームクライアントは作りません。

## 2026-10-25 の状態

添付の Windows 版 DLL から、公式ヘッドレス分岐、WaylithClr 設定、MOD 選択と読み込みの API を静的に確認しました。ZIP 2 個の整合性検査も通過しました。

**今回の環境でゲームを起動した結果ではありません。** Linux 版の実行ファイル・同梱ランタイム、Data、GLSL ソース、アセットパックが不足しています。`Rim_Data.zip` は今回の環境に取り込めず、内容を確認できていません。

`RimWorld by Ludeon Studios.zip` は設定・セーブ・キャッシュの保存フォルダです。ゲームのインストール先や `Rendering/Shaders` の代わりにはなりません。

## ゲームファイルの扱い

公開リポジトリには、ゲーム DLL、公式 Data、アセット、逆コンパイルしたコード、ユーザーの設定・セーブ・生ログを入れません。実行時に、ユーザーが用意した正規インストールを非公開の作業領域へ置く方式です。Anomaly は今回の対象外です。

`.gitignore` は誤追加を減らす補助です。公開前には、追跡対象のファイルと内容も確認します。
