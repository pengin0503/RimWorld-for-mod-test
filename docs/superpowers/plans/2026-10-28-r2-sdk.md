# R2 SDK Implementation Plan

> Implement inline under superpowers:executing-plans, using test-driven-development. One whole-branch review follows.

**Goal:** reduce R2 acquisition overhead with a persistent client and verify real acceleration.
**Architecture:** R2 owns shared selection/atomic caching; a small typed SDK transport owns S3 LIST/streamed GET and connection lifetime. Existing CLI remains default.
**Tech Stack:** Python 3.12+, optional botocore 1.43.120, existing Linux Actions.
**Spec:** ../specs/2026-10-28-r2-sdk-design.md

## Global Constraints

Read-only approved R2 prefixes; no credential values, private paths or assets in public output. Four concurrent downloads; 1 MiB stream chunks; explicit environment keys only. No merge or C/D/Windows expansion.

## Review Focus

Truncated/failed streams preserve old cache and close bodies. Invalid inherited profiles never change the parent. Failed acquisition closes clients. Invalid transport/prefix fails before network. Benchmark equality/caps must fail closed and cached files must not contaminate timing.
