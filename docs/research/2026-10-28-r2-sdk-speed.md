## Change and use

An explicit `RWMT_R2_TRANSPORT=sdk` selects a persistent S3 client instead of one AWS CLI subprocess per object. Both use the same four-download concurrency, selection, size checks, cache logic, private temporary files, atomic replacement and cleanup. The SDK streams 1 MiB chunks, closes each response body and closes the client when acquisition ends or fails. Its per-session configuration ignores inherited profiles/config files without changing the parent environment; it accepts explicit environment credentials only.

```bash
python3 -m pip install -r requirements-r2-sdk.txt
export RWMT_R2_TRANSPORT=sdk
python3 tools/codex_workflow.py prepare --private-root "$RWMT_PRIVATE"
```

The default remains `cli`; `RWMT_R2_TRANSPORT=cli` explicitly selects it. There is no silent fallback when SDK setup fails. The SDK dependency is optional for ordinary CLI use. Existing immutable snapshots are still reused. The existing same-size cache-update limitation is unchanged; this change does not make freshness guarantees stronger.

## Same-object comparison in one runner

Select Version.txt and 31 small Core Def XML files from the approved prefix. The fixed sample is **32 objects / 386,348 bytes**; each object is at most 64 KiB and the sample cap is 2 MiB. Each transport runs three times with fresh destinations, in the order CLI/SDK, SDK/CLI, CLI/SDK. No timed run used a cached destination. SHA-256 of every downloaded object matched across all six trials.

| Pair | CLI seconds | SDK seconds |
|---|---:|---:|
| 1 | 11.328190 | 2.886489 |
| 2 | 10.988870 | 2.834514 |
| 3 | 10.758495 | 2.953626 |
| Median | **10.988870** | **2.886489** |

SDK is approximately **3.81× as fast / 73.73% less time** for this small-file sample. Timings include client initialization/close and downloads, and exclude listing/selection and post-download hashing. Alternating the order reduces simple order bias; this is still a small sample without controlled remote cache or network conditions.

The comparison requires 192 GETs and 2,318,088 payload bytes in total, plus the bounded game-prefix listing. It does not repeat the full CLI runtime download.
