# C0 dynamic reachability probes

This executes the continuation authorized after audit #5. It is development-only research, not a new product case or qualification.

## Decision

Use an independent self-made Harmony observer under the official Linux headless boot and the existing product map boot. Do not copy product predicates or invoke product reflection helpers. Reuse the private snapshot and process supervisor. The alternatives (assuming queue order from IL offsets, or moving C to the D post-FinalizeInit context) do not establish the documented C context and are rejected.

## Event context

Observe GenerateMap postfix, Game.FinalizeInit prefix, and a marker registered with ExecuteWhenFinished from the GenerateMap postfix. Record fixed phase enums, sequence numbers, whether the captured Game/map identity is retained, and FinalizeInit count at the marker. Do not suppress or defer FinalizeInit, replace the official event queue, or run ticks. The official boot must reach its natural marker; request orderly exit there, with an external timeout/RSS/log supervisor always active. Product uses its existing finite map request and retains its normal completion.

The event gate requires generated then marker, same Game/map, no FinalizeInit before the marker, exactly one generation/marker, no earlier unknown diagnostics, and normal process completion on both sides. If the official queue marker executes after FinalizeInit, record context mismatch and stop event comparison. It does not prove that every possible official reference is impossible.

## Material context

After official loading, create a fresh Game/new Bill from the existing billingredients fixture; save and restore Current.Game in finally. Invoke the actual bill dialog ingredient pane through its verified four-float signature. Observe entry to pane, filter UI, listing, and target ThingDef row; do not replace a rendering predicate. Require the actual row method's metadata signature to be read before instrumenting it. An exception before tree/row entry is a concrete stop, not a negative visibility value. Never synthesize a GUI event to make an unverified path appear natural.

## Safety and evidence

Only fixed mode/phase names, booleans and bounded integers leave private storage. Raw exceptions and diagnostics remain private. Each official process has private HOME/XDG, 180 seconds, 2 GiB RSS polling, 8 MiB logs, descendant cleanup; memoryHard remains false. R2 credentials are absent during fixture build/execution. Normal completion of a research trace does not qualify C. Missing, duplicate, malformed, interrupted, context-mismatched or diagnostic-bearing evidence cannot satisfy C0. Cases stop independently.

The next step after a successful context gate is independent material visibility/allowed observation or map stack delta comparison, three positive independent processes, expectation mutations and missing-fixture coverage. Qualification/cache changes remain a separate evidence-bound step. A failed gate ends that case with the exact observed blocker.
