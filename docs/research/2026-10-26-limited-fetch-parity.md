# 有効ロードフォルダに基づく限定取得と全取得の比較

確認日：2026-10-26。対象は PR #9 の限定取得修正。ゲーム側規則・出典は [ロードフォルダ規則](2026-10-26-load-folder-rules.md)。公開するのは集計・手順・判定のみで、索引、MOD、逆コンパイル本文、私有パス、生ログは含まない。

## 対象と構成

R2 から取得済みの正規索引で3 MOD の名前・Workshop ID・PackageId を解決し、各 About.xml と照合した。

| MOD | Workshop ID | PackageId |
|---|---|---|
| Harmony | 2009463077 | brrainz.harmony |
| Vanilla Expanded Framework | 2023507013 | OskarPotocki.VanillaFactionsExpanded.Core |
| Vanilla Psycasts Expanded | 2842502659 | VanillaExpanded.VPsycastsE |

VPE が要求する Harmony・VEF・Royalty を About.xml でも確認。Core → Royalty → Harmony → VEF → VPE の順序、English、A のみを要求した。Linux x64、RimWorld 1.7.4985 rev1269、同梱 WaylithClr。既存ゲームスナップショットを再利用し、ゲームの再ダウンロードは0件。

## 取得対象の比較

数値は検証入力として選択された実ファイルの件数・バイト数。全取得は依頼で明示された3 MOD の prefix に限る。限定側では有効な load folder 内の XML・DLL・言語・画像・音声を選択し、非選択版、ソース、debug、無関係な言語等を省いた。

| MOD | 限定件数 | 限定 bytes | 全取得件数 | 全取得 bytes |
|---|---:|---:|---:|---:|
| Harmony | 4 | 2,549,516 | 16 | 8,306,239 |
| VEF | 204 | 4,271,285 | 650 | 16,716,088 |
| VPE | 726 | 58,187,316 | 1,177 | 80,535,923 |
| 合計 | **934** | **65,008,117** | **1,843** | **105,558,250** |

限定側はファイル数で約49.3%、バイト数で約38.4%少ない。今回の MOD 構成に限った実測で、任意の MOD の削減率を保証しない。

最初の限定取得では207ファイル・5,949,620 bytesを取得した。比較用の全取得ではこの207ファイルを再利用し、不足1,636ファイルのみ GET。画像・音声不足を切り分けた後の最終限定ツリーは、同じ R2 取得済みキャッシュから選択された934ファイルだけを新しい私有領域へコピーし、`fetch-mods --scope validation` で実列挙に対して934件すべてが cache hit となることを確認した。従って表の65 MBを最終実行時にもう一度ダウンロードした、という意味ではない。全取得の比較のために実際に取得したファイルを捨てて再取得することはしていない。

## 不一致の切り分け

1. XML・DLL・言語だけの限定取得は `failed / completed / qualified`、対象で増えた診断669件。VPE のロード時処理で参照するテクスチャが欠けていた。
2. 有効フォルダの画像を含めると、残る381件は音声クリップ・SoundDef の grain 解決エラーだった。
3. 実測で必要性を確認した有効フォルダ内の音声も含めると、全取得と一致した。診断の allow や例外抑制は追加していない。`--scope all` に自動切替していない。

前2回の `failed` は限定入力不足の診断であり、VPE 本体の欠陥と断定しない。最終結果で置き換えて失敗履歴を消さない。

## 合成テストと拒否条件

1.7 不在時の旧版・未来版フォールバック、独自フォルダ、版別定義の選択順、3種類の条件、未知条件、XML 破損・自由テキスト・DTD、存在しない/危険なパス、空の有効フォルダ、通常/版別依存、重複した依存定義、古いキャッシュの空バージョンディレクトリをテストする。判断不能な入力は理由コード付き `blocked`、依存の自動追加なし。選択した空フォルダも作り、フィルターがゲームのフォールバック先を変えないようにする。

## 未確認事項

B/C/D、マップ生成、ほかの言語・DLC構成・MOD、Windows は未検証。A 中に MOD のコードはロードされるが、Harmony パッチ登録の期待値や効果は検査していない。ロード時に利用されない独自リソースや独自のファイル探索を一般に保証しない。未対応の版名・XML エンコーディング等は安全側に拒否する。Linux での合格は Windows や長時間プレイを保証しない。

## 最終の開発チェック

`compileall` 成功。Python 全163件中162件成功、Windows専用GUIの1件スキップ。Worker Release ビルドは警告0・エラー0。独立レビューで指摘された重複/自由テキストの依存定義は、失敗する回帰テストを先に追加して修正し、全体テストを再実行した。計画外のファイルや空ディレクトリが残るキャッシュも拒否し、既存ファイルを削除しない。
